# Wannian_AHS_ecological_connectivity_code

This repository is used to publicly share the code from the research project on ecological connectivity in Wannian County (AHS framework).

## Purpose

The goal of this repository is to make the research code openly available for:

- transparency and reproducibility
- peer review
- reuse and extension by other researchers

## Repository status

The project code and related analysis materials can be organized and published here in incremental updates.
